# Farewell, Andreas Braun! 👋

A collaborative farewell board for [Andreas Braun](https://github.com/alcaeus), built as a [GitHub Pages](https://please.github.io/farewell/) site powered by [Hugo](https://gohugo.io).

Colleagues leave messages by opening a Pull Request — each card is a single Markdown file. No account, no login, no external service.

## Live site

**[https://please.github.io/farewell/](https://please.github.io/farewell/)**

## How to add a card

See [CONTRIBUTING.md](CONTRIBUTING.md) for step-by-step instructions (GitHub web UI or git).

## Local development

```bash
brew install hugo        # or https://gohugo.io/installation/
hugo server
```

Then visit `http://localhost:1313/farewell/`.

## Transfer the repo to Andreas

Once the board is ready, go to **Settings → Danger Zone → Transfer ownership** and enter `alcaeus` as the new owner.
